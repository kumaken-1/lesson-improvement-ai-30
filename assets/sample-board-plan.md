# 練習用の板書計画（架空）

これは生成AIを試すための練習用の素材です。**架空の内容で、実在の学校・児童とは関係ありません。**

**教師のまとめが強い板書計画をわざと書いてあります。**子どもの言葉が、きれいな表現に直されている箇所を探す練習に使ってください。

対象は物語文の1時間です。中心の発問は「なぜハルは、言おうとしたことをのみこんだのか」。

---

## 板書計画

```
┌──────────────────────────────────────────────┐
│ めあて  ハルの気持ちの変化を読み取ろう        │
│                                              │
│ 中心の問い                                    │
│   なぜハルは、言おうとしたことをのみこんだのか │
│                                              │
│  ┌─ 子どもの考え ─────────────┐          │
│  │ ① ミナの気持ちを大切にしたから  │          │
│  │ ② 友情を守りたかったから        │          │
│  │ ③ 本当のことを言うのがつらかった │          │
│  └────────────────────────────┘          │
│                                              │
│ ↓                                            │
│                                              │
│ まとめ                                        │
│   ハルは、ミナの思いを受け止め、友情を大切に   │
│   する気持ちから、あえて言葉を選んだ。         │
│                                              │
│ ふりかえり  分かったこと・感想を書こう         │
└──────────────────────────────────────────────┘
```

---

## 授業中に出そうな子どもの言葉（教師のメモ）

実際の学級では、次のような言い方で出ることが多いと予想している。

- 「なんか、言いにくいと思ったんじゃないかな」
- 「言ったら、ミナが来なくなるかもしれないから」
- 「あの、皿が空だったってところが……よく分かんないけど、それを言いたかったんだと思う」
- 「ハルはべつに、猫のことはどうでもいいのかも」
- （首をかしげて黙る子が数名）

---

## この素材の使いかた

- 添付して使う回では、このファイルをそのまま添付できます。
- AIに渡す前に、「この板書のうち、子どもの言葉のまま残したいのはどこか」を一言書いておいてください。
- 「子どもの考え」の①②③と、下の「授業中に出そうな子どもの言葉」を見比べてください。
